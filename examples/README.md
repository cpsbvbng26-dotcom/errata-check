# 見本 / Examples

どの見本も合成です。本物の論文を置くと、通ったのが道具のおかげなのかその論文のおかげなのかが分かりません。
All examples are made up. With a real paper, one could not tell whether a pass was due to the tool or to the paper.

| 見本 / Example | 見せるもの / What it shows |
| --- | --- |
| [`minimal/`](minimal/) | 引用・件数・不在・数値・未解決・凍結・日付 / quotations, counts, absence, numbers, open items, the frozen source, dates |
| [`disciplines/`](disciplines/) | 検定・GRIM・識別子・算術・元号 / test statistics, GRIM, identifiers, arithmetic, Japanese eras |
| [`references/`](references/) | 参考文献の使い方の宣言 / declared use of references |

## 一分で試す / Try it in a minute

### 1. 走らせる / Run

```
pip install pypdf
python3 errata_check.py examples/minimal/audit.toml
```

渡すもの: 宣言 `minimal/audit.toml`、正誤表 `minimal/ERRATA.md`、凍結された一次資料 `minimal/paper.pdf`。
返るもの: 組ごとの `PASS` の表。最後の行は「すべて通りました。」で、終了コードは 0 です。

In: the declaration `minimal/audit.toml`, the errata `minimal/ERRATA.md` and the frozen source `minimal/paper.pdf`.
Out: a table of `PASS` lines, group by group. The last line ends with 「すべて通りました。」 ("all passed"), and the exit status is 0.

### 2. 壊す / Break it

写しを作り、宣言した件数を一つずらします。
Copy the example and shift the declared count by one.

```
cp -r examples/minimal /tmp/broken
sed -i 's/^expect = 2$/expect = 3/' /tmp/broken/audit.toml
python3 errata_check.py /tmp/broken/audit.toml
```

返るもの: ずらした件数の行だけが `FAIL` になり、「宣言 3 / 実際 2」と出ます。終了コードは 1 です。
Out: only the line for the shifted count is a `FAIL`, saying 「宣言 3 / 実際 2」 (declared 3, found 2). The exit status is 1.

同じ手順を、このリポジトリの CI が Action の形で毎回走らせています（`.github/workflows/verify.yml` の `action`）。
The repository's CI runs the same steps through the Action on every push (the `action` job in `.github/workflows/verify.yml`).

## 作り直す / Rebuild

`paper.pdf`・`record.md` などは各見本の `build.py` の生成物です。手で編集しません。
`paper.pdf`, `record.md` and the like are generated by each example's `build.py`. They are not edited by hand.

```
python3 examples/minimal/build.py
python3 examples/disciplines/build.py
python3 examples/references/build.py
git diff --exit-code -- examples
```
